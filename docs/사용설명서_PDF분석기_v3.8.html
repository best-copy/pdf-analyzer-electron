1. 설치와 처음 실행

1-1. 설치

프로그램은 설치가 필요 없는 포터블 형태입니다. 받은 압축 파일을 원하는 위치(예: D:\PDF분석기)에 풀면 됩니다.

  1. 압축을 푼 폴더에서 설치.bat을 더블클릭합니다. 관리자 권한 확인 창이 뜨면 [예]를 누릅니다.
  2. 설치 스크립트가 한 번만 해 두면 되는 연동을 차례로 묻고 설정합니다.
    • 가상 프린터 PDF Editor — 어떤 프로그램에서든 [인쇄]로 이 앱에 문서를 보냅니다.
    • 탐색기 보내기 메뉴 — 파일 우클릭 → 보내기 → PDF 분석기.
    • Ghostscript — 프린터 판정·폰트 처리에 씁니다. 앱 폴더에 함께 들어 있어 따로 받지 않아도 됩니다.
  3. PDF 분석기.exe를 실행합니다. 바탕화면 바로가기를 만들어 두면 편합니다.
참고 한글(HWP)·Office·Adobe 문서를 자동 변환하려면 그 PC에 해당 프로그램(한컴오피스, MS Office, Photoshop/InDesign)이 설치되어 있어야 합니다. PDF와 이미지는 다른 프로그램 없이 열립니다.

1-2. 체험판 등록

처음 실행하면 인증 창이 뜹니다. 받은 체험 키를 넣고 등록합니다. 인증 창은 언제든 Ctrl+Shift+Alt+L 또는 화면의 인증 배지를 눌러 다시 열 수 있습니다.

  • 인터넷이 되는 PC: 키를 입력하고 등록을 누르면 바로 활성화됩니다.
  • 인터넷이 안 되는 PC: [요청 코드 만들기]를 눌러 나온 코드를 담당자에게 보내고, 받은 활성화 코드를 붙여 넣습니다. 안내 문구는 버튼 바로 아래에 나옵니다.
  • 키는 한 PC에서 한 번만 쓸 수 있습니다. 다른 PC에서는 새 키가 필요합니다.
  • 사용 기간 연장: 기간이 끝나면 담당자에게 새 키를 받아 같은 방법으로 등록합니다. 작업 중인 파일·설정은 그대로 남습니다.

1-3. 주간·야간 테마

시작 화면 왼쪽 위의 주간 / 야간 버튼, 또는 왼쪽 패널 머리의 달·해 단추로 화면 밝기를 바꿉니다. 고른 테마는 다음 실행에도 유지됩니다.

3. 파일 열기

3-1. 여는 방법

  • 파일을 창에 끌어다 놓기 또는 [파일 선택하기]. 여러 파일을 한 번에 고를 수 있습니다.
  • 탐색기에서 파일 우클릭 → 보내기 → PDF 분석기.
  • 다른 프로그램에서 인쇄 → PDF Editor 프린터를 고르면 결과가 앱으로 들어옵니다.
  • 작업 파일(.pdfw)은 더블클릭 또는 Ctrl+O로 엽니다(10장).

3-2. 여러 파일 — 합쳐 열기

여러 파일을 고르면 열 순서 창이 뜹니다. ▲▼나 끌어서 순서를 정하고 합쳐 열기를 누르면 한 문서로 열리고, 파일마다 챕터로 구분됩니다(6장). 따로 열면 파일마다 탭이 생깁니다.

3-3. 자동 변환되는 형식

형식방법
PDF그대로 엽니다.
한글 HWP · HWPX한컴오피스로 PDF 변환. 한글의 보안 확인 창은 앱이 변환 중인 파일에 대해서만 자동으로 허용합니다.
Word · Excel · PowerPointMS Office로 PDF 변환(매크로는 실행하지 않음).
AI · PSD · INDDAI는 바로, PSD는 Photoshop, INDD는 InDesign으로 변환.
이미지 (PNG·JPG·GIF·BMP·WEBP·TIFF)파일에 기록된 해상도(DPI)대로 실제 인쇄 크기의 1쪽 PDF로 만듭니다. 기록이 없으면 큰 이미지는 300DPI, 작은 이미지는 96DPI로 봅니다.
참고 변환 중에 해당 프로그램을 쓰고 있었다면 앱은 자기가 연 문서만 닫고, 사용자가 열어 둔 문서는 건드리지 않습니다.

4. 분석 결과 읽기

파일을 열면 쪽마다 컬러인지 흑백인지 자동으로 판정합니다. 결과는 왼쪽 패널 요약과 가운데 카드에 같이 나옵니다.

  • 전체 / 컬러 / 흑백 / 컬러 비율 — 견적과 프린터 과금의 기준입니다.
  • 컬러 페이지·흑백 페이지 번호 — 예: 1, 3, 6, 9, 12. 그대로 복사해 견적·작업지시에 씁니다.
  • 판정 기준 — 색이 조금이라도 있으면 컬러입니다. 먹(K) 한 가지나 회색(C=M=Y)으로만 된 쪽은 흑백으로 봅니다.
  • 쪽 썸네일을 더블클릭하거나 V를 누르면 크게 보기 창이 열려, 색이 있는 곳을 눈으로 확인할 수 있습니다.
  • 프린터 판정 버튼은 프린터가 실제로 컬러로 셀지(잉크 사용량 기준)를 따로 계산합니다.
속도 분석은 주로 CPU를 씁니다. 쪽 수가 많은 문서는 사무용 저사양 PC에서 몇 배 오래 걸릴 수 있습니다. 한 번 오래 걸린 문서는 결과를 기억해 두었다가 다음에 바로 엽니다.

5. 흑백 처리

5-1. 흑백으로 찍을 쪽 고르기

  1. 쪽 썸네일을 클릭해 고릅니다. Shift·Ctrl+클릭으로 여러 쪽, [컬러만 전체 선택]·[모두 선택]·[선택 해제] 버튼도 있습니다.
  2. [흑백변환]을 누르거나 우클릭 메뉴 원본 페이지 컬러 모드 → 흑백(B)을 고릅니다. 다시 컬러로 되돌리려면 C.
  3. [✔ 적용]을 누르면 결과에 반영됩니다.

흑백으로 바꾼 쪽은 사진·글자·도형·투명 효과까지 모두 회색 잉크(DeviceGray)로 다시 만들어 프린터가 흑백으로 셉니다.

5-2. 처리 옵션

옵션설명
잉크 정규화 (기본 켬)원래부터 흑백으로 판정된 쪽도 회색 잉크로 정리합니다. 화면에선 흑백인데 프린터가 컬러로 세는 쪽(CMYK로 만든 검정·회색)을 막아 줍니다. 특별한 이유가 없으면 켜 두십시오.
Dot Gain (없음·10·15·20%)흑백 쪽의 중간 회색을 조금 밝게 해, 인쇄에서 망점이 번져 어두워지는 것을 보정합니다. 켤 때마다 '없음'에서 시작합니다.
프리플라이트저해상도 그림, 포함되지 않은 글꼴, 블리드 부족 등을 미리 검사합니다.
저장 전 확인 저장할 때 흑백으로 정한 쪽에 색이 남아 있거나, 원래 컬러였는데 흑백이 된 쪽이 있으면 저장 전에 알려 줍니다.

6-2. 챕터

여러 파일을 합쳐 열면 파일마다 챕터가 됩니다. 챕터 머리줄의 단추로 챕터 단위 작업을 합니다.

  • 편집 — 그 챕터 쪽만 화면에 모아 보고 편집합니다.
  • ▲ ▼ — 챕터 순서를 바꿉니다. 휴지통 — 챕터를 통째로 지웁니다(확인 후).
  • 쪽 수 표시는 빈 쪽을 넣거나 지우면 바로 바뀝니다.

잘못 고쳤으면 Ctrl+Z(되돌리기), Ctrl+Y(다시 하기).

7. 편집 모드

화면 오른쪽 끝의 편집 모드(또는 E)를 누르면 작업공간이 열립니다. 왼쪽에서 설정하고 오른쪽에서 결과를 바로 확인합니다. 가운데 경계를 끌어 좌우 폭을 조절합니다.

섹션내용
설정 프로파일 · 최근 작업 설정지금 설정을 이름 붙여 저장하고 불러옵니다. 불러오면 저장된 값으로 모두 바뀝니다.
적용 범위전체 / 선택 페이지 / 범위 / 챕터 중 설정을 적용할 곳.
페이지 방향 맞춤가로 원고를 자동으로 돌려 방향을 맞춥니다.
크기 · 여백 · 제본여백 · 블리드용지 크기·배율, 여백(mm), 제본 쪽 여백, 블리드(재단 여유) 생성.
기울기 · 정렬 · 개별 보정스캔 원고 기울기 보정, 내용 가운데 정렬, 쪽별 개별 보정.
테두리 · 표지 만들기쪽 테두리, 앞·뒤표지와 책등 자동 생성(책등 폭 계산).
머리글·바닥글 · 페이지 번호 · 워터마크문구·글꼴·위치, 쪽 번호 형식, 반투명 워터마크.
조판(모아찍기) · 임포징8장 참고.
내부 내용 편집쪽 안 글자·요소 편집 창을 엽니다.
  • 오른쪽 위 결과 보기 / 원본 보기로 비교합니다. 펼침은 양면 펼친 모양으로 보여 줍니다.
  • 실시간 편집반영을 켜면 값을 바꿀 때마다 미리보기가 갱신됩니다.
  • 끝나면 저장하고 닫기(설정 반영), 반영 없이 나가려면 닫기 또는 Esc.

8. 임포징(제본 조판)

편집 모드의 임포징 (제본 조판) 섹션에서 켭니다. 방식을 고르고 용지·그리드·인쇄 면을 정하면 오른쪽에 시트 결과가 나옵니다.

방식설명
중철가운데를 스테이플로 묶는 책자. 쪽 순서를 접지 순서로 자동 배치합니다. 4의 배수가 아니면 빈 쪽을 채웁니다.
모아찍기연속된 쪽을 한 시트에 열×행으로 앉힙니다(슬라이드 유인물 등). 양면이면 뒷면은 좌우 대칭으로 배치합니다.
반반시트를 2·4분할해 인쇄 후 잘라 쌓으면 순서대로 되도록 배치(Cut & Stack).
반복같은 쪽을 시트 가득 반복(명함·스티커 등).
복제 2부한 시트에 같은 쪽 두 부를 앉혀 두 권을 한 번에 찍습니다.

공통 설정

  • 용지: 자동(원본 기준)·표준 용지·사용자 정의. 인쇄: 양면/단면.
  • 거터: 원고(재단선) 사이 간격 그대로입니다. 양끝 맞춤은 원고를 시트 좌우 끝에 붙이고 간격을 자동으로 잡습니다.
  • 여백 · 블리드 채움 · 원고 블리드, 재단선(모서리·겹침 없음·이중 코너), 프레임, 슬러그(시트 정보).
  • 배치: 칸 맞춤 / 100% 원본 / 지정%. 위치와 미세이동(mm).
  • 프리셋: 자주 쓰는 임포징 설정을 저장·불러오기.

챕터별 임포징

  • 모아찍기는 챕터가 둘 이상이면 항상 챕터별로 앉힙니다. 한 시트에 두 챕터가 섞이지 않고, 챕터 끝 시트의 남는 칸은 빈칸으로 둡니다.
  • 양면 인쇄일 때는 다음 챕터가 새 종이의 앞면에서 시작하도록 빈 시트가 자동으로 들어갑니다(그림 7의 4번 시트).
  • 중철·반반 등은 챕터(파일)별로 따로 임포징을 체크했을 때만 챕터별로 나눕니다.

9. 적용 · 다운로드 · 분리 저장

9-1. 적용

[✔ 적용]을 누르면 흑백·편집·임포징이 모두 반영된 결과가 가운데에 나옵니다. 결과 화면에서도 챕터 구분선이 유지되며, 구분선의 편집 · ▲▼ · 휴지통으로 챕터를 고치면 자동으로 다시 적용됩니다. 설정을 바꿨는데 화면이 그대로면 F5(결과 새로고침).

9-2. 다운로드

  • [⇩ 다운로드] 좌클릭 = 적용본, 우클릭 = 원본 그대로 저장합니다. 챕터는 한 PDF로 합쳐서 저장됩니다. [목차 생성]으로 만든 목차 북마크가 있으면 함께 들어갑니다.
  • 저장 기본 폴더는 원본 파일이 있던 폴더입니다.

9-3. 목차 생성 · E-book 시안

  • 목차 생성: 장이 시작하는 쪽들을 고르고 누르면 제목을 자동으로 읽어 목차 쪽과 PDF 북마크를 만듭니다.
  • E-book 시안: 고객 확인용으로 책장을 넘겨 보는 HTML 파일 하나를 만듭니다. 일반 웹용·모바일용, 양면(펼침)·단면, 표준·고화질, 제본 방식(책자·트윈링·하드커버·리플렛)을 고릅니다.

9-4. 분리 저장

[✂ 분리 저장]은 완성본을 N쪽 단위(10·20·대수 16 등) 또는 쪽 범위(21-39, 1-20, 41-60)로 나눠 한 폴더에 저장합니다. 좌클릭은 적용본, 우클릭은 원본입니다. 나눈 파일에는 목차 북마크가 들어가지 않습니다.

9-5. 폰트 출력 안전화

인쇄소·출력실에서 글꼴이 바뀌거나 빠지지 않도록 저장할 때 글꼴을 정리합니다.

방식설명
폰트 완전 임베드글꼴을 파일 안에 모두 넣습니다. 빠르고 용량이 작습니다. 권장.
곡선화글자를 도형(윤곽선)으로 바꿉니다. 글꼴 문제는 완전히 없어지지만 시간이 오래 걸리고 용량이 커지며 글자 수정이 안 됩니다.
평탄화투명 효과를 합쳐 구형 출력기에서도 같은 모양이 나오게 합니다.

다운로드 버튼 옆 abc 표시는 안전화가 켜져 있다는 뜻입니다.

10. 작업 파일(.pdfw)

작업 파일은 원본 + 모든 설정 + 적용 결과를 한 파일에 담습니다. 다시 열면 계산 없이 저장할 때 화면 그대로(챕터 구분 포함) 돌아옵니다.

동작방법
저장 (지금 파일에 덮어쓰기)왼쪽 패널 [작업 저장] 또는 Ctrl+S
다른 이름으로 저장[다른 이름으로 저장] · [작업 저장] 우클릭 · Ctrl+Shift+S
열기[작업 열기] · Ctrl+O · .pdfw 더블클릭

앱을 닫을 때 저장하지 않은 작업이 있으면 저장 / 다른 이름으로 저장 / 저장 안 함 / 취소를 묻습니다.

참고 작업 파일은 원본과 결과를 함께 담아 PDF보다 큽니다. 2GB가 넘는 작업도 저장·열기가 됩니다.

12. 자주 묻는 질문과 문제 해결

Q. 앱은 흑백이라는데 프린터가 컬러로 셉니다.

CMYK로 만든 검정·회색(리치블랙)이 원인인 경우가 많습니다. 잉크 정규화를 켜고 그 쪽을 흑백(B)으로 지정한 뒤 적용·저장하십시오. [프린터 판정]으로 저장 전에 프린터 기준 결과를 확인할 수 있습니다.

Q. 분석·변환·저장이 다른 PC보다 많이 느립니다.

이 프로그램은 주로 CPU를 씁니다. 코어·스레드가 적은 사무용 PC에서는 3~4배 걸릴 수 있습니다(메모리·디스크 영향은 작습니다). 큰 작업 중에는 다른 무거운 프로그램을 닫아 두십시오. 곡선화는 특히 오래 걸리므로 보통은 폰트 완전 임베드를 쓰십시오.

Q. 다운로드할 때 글꼴 처리 오류가 납니다.

오류 창에 Ghostscript가 알려 준 원인이 함께 표시됩니다. 그 문구를 담당자에게 전달해 주십시오. 앱 폴더를 옮기면서 resources\gs 폴더가 빠지지 않았는지도 확인하십시오.

Q. 한글(HWP) 변환이 멈추거나 실패합니다.

한컴오피스가 설치되어 있는지, 한글에 열려 있는 저장 확인 창이 없는지 확인하십시오. 한 번에 한 파일씩 차례로 변환합니다.

Q. 화면이 갱신되지 않거나 이상합니다.

F5(결과 새로고침)를 먼저, 그래도 안 되면 Ctrl+Shift+R(앱 새로고침)을 누르십시오. 그 전에 작업 파일로 저장해 두면 안전합니다.

Q. 체험 기간이 끝났습니다.

담당자에게 새 키를 받아 인증 창(Ctrl+Shift+Alt+L)에서 등록합니다. 저장해 둔 작업 파일과 설정은 그대로 쓸 수 있습니다.

Q. 다른 PC로 옮기려면?

앱 폴더를 통째로 복사한 뒤 새 PC에서 설치.bat을 한 번 실행하고, 그 PC용 키로 등록합니다.
